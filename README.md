# Just-Keep-Swimming
Just Keep Swimming is a fun website about emotions specially the ones that are normally considered "Negative", the main goal is to understand how they work and how we can take out the best of them.
The website has different pages each one for a different emotion or feeling,
<ul>
<li>Anger</li> 
<li>Anxiety</li>
<li>Fatigue</li>
<li>Fear</li>
<li>Nostalgia</li>
<li>Sadness</li>
<li>Stress</li>
</ul>

Check out the website through this link:
https://isabellagg19.github.io/Just-Keep-Swimming/

In the building of Just Keep Swimming Website I used
HTML, for the different pages structures
CSS, for the organization and design of all the pages

In the making I understood how to add different pages in just one website, which was really cool, and how to give to each page a unique design, as well as manage difficulties like making each page look organized.

I really hope you enjoy this website, and for it to remind you that the most human thing we can do is to feel our emotions.
